How This Number Was Calculated

Each permission group (Owner, Group, Others) gets one digit, from 0 to 7. That digit is a sum of three binary weights: read = 4, write = 2, and execute = 1. Only checked permissions count toward the total.

How Chmod Permission Numbers Work

Linux file permissions are split into three groups that always appear in the same order: the owner of the file, the group the file belongs to, and others (everyone else). Each group can independently be granted read, write, and execute access, which is why permissions are usually written as three sets of three characters, like rwxr-xr-x.

To turn that into a single digit, each of the three permissions is assigned a power of two: read is worth 4, write is worth 2, and execute is worth 1. Because 4, 2, and 1 are each represented by a different bit, every possible combination of on/off produces a unique sum between 0 and 7 — there's no ambiguity about which permissions are enabled just from looking at the number.

Step-by-Step Example: 755

  • Owner (7): read (4) + write (2) + execute (1) = 7 → full access.
  • Group (5): read (4) + execute (1) = 5 → write is off, so 2 is skipped.
  • Others (5): read (4) + execute (1) = 5 → same as group.
  • Combined, this gives the octal number 755, equivalent to rwxr-xr-x — a very common setting for scripts and executables.

Why You Can't Get, Say, "3" from Read Alone

Because each weight (4, 2, 1) is a distinct power of two, every digit from 0-7 maps to exactly one combination of permissions: 0 = none, 1 = execute only, 2 = write only, 3 = write + execute, 4 = read only, 5 = read + execute, 6 = read + write, 7 = read + write + execute. This is the same logic as binary flags, just written in base 8 (octal) because three bits fit neatly into one octal digit.

Special Permission Bits

  • Setuid (4000): runs an executable with the file owner's privileges instead of the user running it.
  • Setgid (2000): on a file, runs with the group's privileges; on a directory, new files inherit that directory's group.
  • Sticky bit (1000): on a directory, only the file's owner (or root) can delete or rename files inside it, even if others have write access.
  • These add an optional fourth leading digit, e.g. 4755 for setuid + rwxr-xr-x.

Developer Quick Reference

  • Numeric mode: chmod 755 file.sh
  • Symbolic mode: chmod u=rwx,g=rx,o=rx file.sh
  • Add execute for all: chmod +x file.sh
  • Recursive (directories): chmod -R 755 folder/
