What is a Hash Function?

A cryptographic hash function takes an input of any size and produces a fixed-length string of characters, called a digest, that uniquely represents that input. Even a single character change in the input produces a completely different hash. Hashes are commonly used to verify file integrity, store password fingerprints, and detect duplicate content.

Which Algorithm Should I Use?

  • MD5: Fast and widely supported, but not collision-resistant. Fine for checksums, unsafe for security.
  • SHA-1: Deprecated for security purposes due to known collision attacks.
  • SHA-256 / SHA-512: Part of the SHA-2 family, currently considered secure and widely used for passwords, signatures, and blockchains.

Developer Quick Reference

  • JavaScript: crypto.subtle.digest('SHA-256', data)
  • Python: hashlib.sha256(data).hexdigest()
  • Bash / Linux: echo -n "text" | sha256sum
  • PHP: hash('sha256', $text)
