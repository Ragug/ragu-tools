What is a JWT Secret Key?

A JWT secret key is the shared random string used to cryptographically sign and verify JSON Web Tokens with HMAC-based algorithms (HS256, HS384, HS512). Anyone holding the secret can mint valid tokens, so it should be long, unpredictable, and generated with a cryptographically secure random source rather than typed by hand.

Recommended Key Sizes

  • HS256: at least 32 bytes (256 bits) so the key is as strong as the hash algorithm.
  • HS384: at least 48 bytes (384 bits).
  • HS512: at least 64 bytes (512 bits).
  • Using a shorter secret than the algorithm's output size weakens the signature and makes brute-force forgery easier.

Developer Quick Reference

  • Node.js: crypto.randomBytes(32).toString('base64')
  • Python: secrets.token_urlsafe(32)
  • OpenSSL: openssl rand -base64 32
  • Bash / Linux: head -c 32 /dev/urandom | base64

Treat this like any other secret: never commit it to source control, rotate it periodically, and store it in an environment variable or secrets manager rather than in code.
